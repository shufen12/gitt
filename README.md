# Git

A repository initialized for local work, synced to GitHub.

## Getting started

```bash
git clone <repository-url>
cd Git
```

## Layout

```
.
├── README.md
└── .gitignore
```

## Contributing

1. Create a branch: `git switch -c feature/my-change`
2. Commit your work: `git commit -m "feat: describe the change"`
3. Push and open a pull request: `git push -u origin feature/my-change`
